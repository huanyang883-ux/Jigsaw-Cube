# 图片制作规范

- 所有关卡图片统一使用 **2:3 竖图**。默认生成 PNG 1024×1536；更高分辨率也必须严格保持 2:3，且不得小于 960×1440。游戏统一导出 WebP 960×1440。
- 只有魔方六面的章节贴图（文件名以 `-face` 结尾）使用 **1:1 方图**。现有方形封面不随关卡比例调整而改动。UI 图标、透明手套等独立界面素材不属于关卡图片。
- 新建、替换、变体和后续扩展章节都遵守此规范。当前可用提示词在 `catalog.json`；历史实验目录保留当时记录，不作为当前尺寸规范。
- 调整既有图片比例时，参考原图适度扩展环境，保留主体、动作、配色和难度线索；禁止拉伸、压扁、加纯色边框或通过裁掉重要主体凑比例。使用内置 imagegen，并检查生成结果。
- 新图保留清楚可辨的主体和连续轮廓。难图可用群居、拟态、相似色与重复纹理增加辨认需求，同时保留方向、遮挡和细节差异。章内注意不同环境、动作、视角和色彩带来的新鲜感。
- 四阶及以后可以偏难，优先自然纪实感、较大景深、日常光照与完整场景，减少棚拍、强虚化和孤立主角式艺术照。用相似材质、建筑结构、织物纹样和遮挡增加难度，仍需给各区域留下可辨认的连续线索。
- 单纯修改图片不改变关卡块数、初始排列、完整解法和存档版本。三阶魔方全部关卡的零初始连接约束继续保留。
- PNG 原图放在 `images/`，游戏 WebP 放在 `public/assets/`。原图本地备份、最终提示词、生成输出对应关系和验证结果保存在本次实验目录。
- Git 只提交游戏运行素材、当前提示词和必要的测试基准。`experiments/` 默认忽略，现有测试依赖的 JSON 基准在根目录 `.gitignore` 中明确放行；不要强制提交实验图片、重复备份或生成报告。
- 运行 `npm run art:optimize`，该脚本先验证全部原图的比例，再导出并更新 `src/art-manifest.json`。不要绕过比例校验。
