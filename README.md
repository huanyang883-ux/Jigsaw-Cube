# 魔方拼图

PixiJS + Three.js 本地 H5 拼图，设计分辨率 **1080 × 1920**，等比例适配手机竖屏。界面使用图标与道具数量，包含卡通甜品与写实动物两个主题，四阶魔方保留沙漏入口。

## 启动与手机试玩

Windows 双击 start-game.cmd，浏览器自动打开。构建版 dist/ 已包含在项目中，运行只需 Node.js 22+，不依赖外部网络。修改源码后执行 npm run build 更新构建。

服务监听 0.0.0.0，默认端口 4173，占用时寻找 4174–4182。启动窗口输出 LAN 地址，手机与电脑连接同一局域网后打开该地址。电脑需保持开机与服务运行，各设备独立保存进度。本机防火墙规则 SweetCubePuzzle-LAN 仅允许本地子网访问这些端口。

开发运行 npm install 和 npm run dev，默认地址 http://localhost:5173，同样支持局域网。

## 游戏内容

- 首页魔方缓慢随机旋转，拖动可自由旋转查看，松手后恢复慢转。左右立体箭头切换二、三、四阶，拖动不会切换主题。
- 点击已解锁魔方，平滑放大并对准当前进度面；右上角返回恢复进入前的角度与大小。选关界面保持正面，仅用左右箭头查看已解锁章节。
- 魔方面选关页不再显示顶部章节预览图；首页保留主题图标。局内眼睛预览和通关展示直接复用关卡图片，无独立缩略图资源。
- 六面顺序：正、右、背、左、上、下。一面完成后解锁下一面；二阶六面全部完成后解锁三阶。
- 二阶：6 面 × 4 关，共 24 关，每关平均切为 3×3。六章是蛋糕、糖果、果冻、冰淇淋、巧克力、奶油。
- 三阶：6 面 × 9 关，共 54 关，每关平均切为 4×4。六章依次为海洋生物、两栖生物、陆地生物、昆虫、鸟类、古生物。动物与栖息环境共同构图；古生物为照片质感的场景复原。
- 共 90 张独立图片：12 张方形章节图、78 张关卡图。保留初版 4 张方形蛋糕关卡，其余关卡使用 3:4 竖图。
- 棋盘保持原图比例，不拉伸、不裁切，图片平均切分。正确连接的拼片内部没有间隙，整组拖动时保持连续；未连接的边保留细缝。遇到边界无法移动时，整组沿拖拽方向轻微倾斜并回弹，实际位置不变。
- 关卡出场：背面静止 0.5 秒 → 独立、小范围、由弱到强震动 1 秒 → 随机顺序、随机间隔翻面 2 秒，翻转时轻微抬起并平稳落定。第一帧即显示背面，动画期间锁定拼图与道具操作；系统开启减少动态效果时跳过震动与长演出。
- 拼片背面与魔方共用糖果图案、奶油色底和柔和描边；竖图延展底板，糖果图案保持原比例。图案由 Canvas 生成，不增加图片下载。
- 保留拖动交换、相邻合组、整组拖动、占位让位、提示、原图预览和进度存储。下方仅保留灯泡提示与眼睛预览两个按钮，角标显示数量；移除撤销、重排与顶部缩略图。竖图拼图区扩大，仍按原图比例平均切割。
- 提示和预览初始各 28 次，全关卡共用。每打开一次原图扣 1 次预览；提示实际移动成功才扣 1 次提示，计算失败或无可用提示不扣。用完按钮禁用，刷新、换关不会补充。沿用 v2 存档，旧存档保留全部进度并初始化道具数量。
- 未通过的魔方图块显示通用背面，通过后揭开章节图的对应切片。四阶仍为扩展占位，不能进入；隐藏面进度与重复状态图标，仅按钮显示沙漏。
- 白手套右手以食指点击、拖动做弱引导，没有文字、遮罩或强制操作。首页闲置 3 秒指向进入按钮，继续到 5 秒切换为旋转魔方示意；选关页闲置 5 秒指向当前面第一个未完成关卡；第一次尚未掌握拖动时，在出场结束后示意一次合法拖动路径。
- 四种操作分别记入存档，玩家提前做过也永久关闭对应引导。点击魔方与进入按钮均视为已掌握进入章节；提示道具自动移动不算玩家拖动；仅点击拼片不算拖动。任何输入都会隐藏当前手势并重计闲置时间，弹窗、加载、出场演出与后台页面不显示手势。

## 图片和性能

- 游戏加载 WebP：章节图最长边 768px，关卡图限制在 1080×1440 内，质量 83。已移除全部 90 张未使用的缩略图及其生成、加载逻辑，减少约 1.4 MB 资源。
- HTML 内置无文字加载画面，主脚本下载期间也能显示。启动并行加载游戏模块、手套和下一可玩关卡图片；已有完成进度时同时准备需要展示的魔方面贴图。进关图片尚未就绪时显示同一图形进度条，失败显示重试图标。
- 下载后验证图片能否解码，避免损坏文件被误判为加载完成。脚本下载失败、资源报错或 45 秒没有进展时显示重试图标。首次点击普通重载；再次失败后点击会取消预取、清空资源内存缓存，仅删除 `sweet-cube:assets:` 名称前缀的 Cache Storage，并从网络刷新已使用的游戏资源，再重新进入游戏。浏览器没有选择性删除 HTTP 缓存的接口，因此 HTTP 缓存使用 `cache: 'reload'` 下载覆盖。清理或下载失败仍保留重试入口，不自动无限重试。
- 恢复控制代码内置在 HTML 中，主模块未下载也能使用；普通局域网 HTTP 无 Cache Storage 时也能强制下载。恢复计数只使用独立的 sessionStorage 键，完全不清除玩家 localStorage：通关、未完成拼图位置、道具、声音设置和引导记录均保留，也不删除其他应用的缓存。
- 当前场景就绪后，低优先级、串行预取当前章节贴图和邻近 2 关；不一次性下载 90 张图片。已预取的图片由浏览器 HTTP 缓存复用，避免进关重新传输。预加载减少游戏中的等待，外网首开速度仍取决于网络和隧道质量。
- 拼片共享一张 GPU 纹理，以独立 UV 连续取样。手机画布按实际显示尺寸与像素比设置，减少过度渲染。
- 图片 URL 带内容版本，支持长期缓存；更新图片后版本自动变化。正式服务为文本资源提供 gzip、ETag 与 304。
- 原始 PNG 在 art-source/images/，保留用于后续修改，不进入 dist/。游戏 WebP 在 public/assets/，旧公共目录 PNG 副本及独立缩略图目录已移除。旧缩略图备份在 .local/unused-thumbnails/，不参与构建。
- 新增 85 张图通过内置 imagegen 生成，完整提示词在 art-source/catalog.json；初版 5 张图的提示词在 art-source/initial-prompts.txt。压缩统计在 art-source/optimization-report.json。
- 白手套由内置 imagegen 生成，原图与提示词在 art-source/ui/，游戏使用 public/assets/ui/guide-hand.webp：384×384、透明 Alpha、约 11 KB。

替换原图后运行：

    npm run art:optimize
    npm run build

优化脚本只转换有变化的原图，同时更新 src/art-manifest.json 的尺寸与内容版本。替换素材时维持文件 ID 即可。

## 代码与扩展

- src/progress.js：主题、章节、图片配置、道具库存、存档与解锁。
- src/puzzle.js：3×3 / 4×4 拼图交换与合组。
- src/piece-geometry.js：连接边几何与 UV、照片棋盘布局。
- src/renderer.js：Three.js 拼片与拖动、PixiJS 轮廓与粒子。
- src/card-back.js：魔方和拼片共用的糖果牌背，适配照片比例。
- src/intro.js：关卡出场时序、随机翻面排程与逐块震动。
- src/cube-scene.js：3D 魔方、立体箭头、旋转、转面、放大、揭图和演出。
- src/main.js：首页 / 章节 / 关卡状态和图标交互。
- src/guide-state.js、src/idle-guide.js：引导触发、学习记录、合法拖动示意与手指动画。
- index.html、src/boot.js、src/loading.js、src/preload.js：首屏加载、无文字进度、资源校验、缓存恢复与后续关卡预取。
- scripts/serve.mjs：局域网静态服务、压缩与缓存。

CubeScene.showcase(kind) 为展示动画扩展点，kind 为 chapter 或 theme。它在 #cube-host 派发 cube-showcase-start/end，detail 包含主题与面编号；演出结束后才继续翻面或切换魔方。当前提供旋转、缩放和粒子效果。
